- Administrator login to view all users’ information
- Corresponding features:
  - Storage role data of users
  - Provide APIs to login as an administrator
  - Provide APIs to retrieve the list of all users
  - Provide APIs to retrieve the details of a specific user

- Administrator login to view all articles, including draft and published articles, and deletes any article
- Corresponding features:
  - Provide APIs to retrieve all articles in the system
  - Provide APIs to filter articles by status, keyword, pagination, and sort order
  - Provide APIs to view draft and published articles of any user
  - Provide APIs to delete any article as an administrator

- Administrator login to view and delete any comments
- Corresponding features:
  - Provide APIs to retrieve all comments in the system
  - Provide APIs to retrieve comments under a specific article
  - Provide APIs to delete any comment as an administrator
